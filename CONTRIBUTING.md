# Contributing to myEElab

Thank you for your interest in contributing to myEElab! All open-source contributions must be targeted at `packages/core`.

## Developer Certificate of Origin (DCO)

We require a Developer Certificate of Origin (DCO) for all contributions. By contributing to myEElab, you assert that you have the right to submit the code under the open-source license.
To indicate that you agree to the terms of the DCO, you just need to add a `Signed-off-by` line to your commit messages:

`Signed-off-by: Jane Doe <jane.doe@example.com>`

## Workflow
1. Look for issues labeled "good first issue" if you are a new contributor.
2. Fork the repository and create your branch.
3. Ensure that all tests pass locally. Our CI gating requires tests to pass before a merge is allowed.
4. Submit your PR and ensure your commits are signed off!
